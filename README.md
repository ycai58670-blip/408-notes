## 推荐使用方式

1. 先按科目完成基础知识复习，建立完整知识框架。
2. 配合 `408笔记/` 整理易错点和高频考点。
3. 使用 `2009-2023计算机408统考真题/` 进行分年份限时训练。
4. 做完真题后再查看 `真题解析/`，重点记录错误原因。
5. 考前集中复盘错题、代码题和常考概念。

## 上传 GitHub 建议

如果准备公开仓库，建议只上传：

- 自己整理的笔记、错题、复习计划、知识框架；
- 可以公开传播的资料索引；
- 不涉及版权风险的原创内容。

不建议公开上传：

- 未获授权的教材、商业课程、机构讲义；
- 带有明显来源推广信息的 PDF；
- 体积过大的扫描版书籍或课件。

如果只是个人备份，可以创建 GitHub 私有仓库。

## 本地上传 GitHub 步骤

```powershell
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

如果本地没有安装 Git，也可以在 GitHub 新建仓库后，点击网页上的 **Add file** 或 **Upload files** 直接上传文件。
